# Python CLI Task Manager
A simple CLI task manager written in Python with JSON-based persistence

## Features
- Add tasks
- Marks tasks as complete
- Delete tasks
- View all tasks, completed tasks and pending tasks
- Edit task descriptions
- JSON-based persistent storage

## Future Improvements
- Add time stamps such as when the task was created and due dates
- Add search filter using keywords
- Upgrade the project to a web-based app using FastAPI

## Technologies
- Python 3.14+
- JSON file storage
